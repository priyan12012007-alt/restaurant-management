# Restaurant Management System

A beginner-friendly Restaurant Management System built using React, Vite, and JSON Server.

## Features

- View all menu items
- Add new menu items
- Edit existing menu items
- Delete menu items
- Form validation
- Loading state
- Error handling
- Responsive design

## Technologies Used

- React
- Vite
- JavaScript
- JSON Server
- REST API
- Fetch API
- CSS

## CRUD Operations

| Operation | Method | Description |
|---|---|---|
| View Items | GET | Fetch menu items |
| Add Item | POST | Add a new menu item |
| Update Item | PUT | Update an existing item |
| Delete Item | DELETE | Delete a menu item |

## Menu Item Fields

Each menu item contains:

- ID
- Name
- Category
- Price
- Availability
